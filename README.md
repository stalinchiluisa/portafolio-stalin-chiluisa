# Portafolio Personal

## Estudiante
Stalin Paul Chiluisa Baidal

## Descripción
Este proyecto consiste en el desarrollo de un portafolio personal utilizando HTML y CSS para la materia Programación de Sistemas Web.

El sitio presenta información personal, habilidades, proyectos académicos y una sección de contacto.

## Tecnologías utilizadas
- HTML5
- CSS3
- GitHub
- GitHub Pages

## Estructura del proyecto
- index.html
- styles.css
- carpeta img

## Visualización del proyecto
Para visualizar el proyecto localmente, se debe descargar el repositorio y abrir el archivo `index.html` en un navegador web.

También se puede acceder mediante GitHub Pages una vez publicado.
