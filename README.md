## Descripción
Este proyecto corresponde a la actualización del portafolio personal desarrollado para la materia Programación de Sistemas Web.

En la Actividad Integradora 2 se incorporaron funcionalidades interactivas utilizando JavaScript, manteniendo la estructura desarrollada previamente con HTML y CSS.

## Nuevas funcionalidades implementadas

- Modo oscuro y modo claro.
- Persistencia del modo seleccionado utilizando LocalStorage.
- Botón para mostrar y ocultar información de la sección "Sobre mí".
- Manipulación dinámica de elementos del DOM.
- Uso de eventos mediante addEventListener().
- Validación del formulario de contacto.
- Mensajes de error cuando existen campos vacíos.
- Mensaje de confirmación cuando el formulario se completa correctamente.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
- GitHub
- GitHub Pages

## Instrucciones para ejecutar el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.
4. También se puede acceder directamente mediante GitHub Pages.
